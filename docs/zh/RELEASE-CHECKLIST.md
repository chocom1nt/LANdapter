# 发布准备检查清单

## 构建与依赖

- [ ] CI 使用 `go.mod` 要求的 Go 版本并通过。
- [ ] 前端测试、生产构建和依赖审计通过。
- [ ] 检查依赖安全公告，完成修复或记录明确的风险决定。
- [ ] 从干净 checkout 成功构建 Docker 镜像。

## 功能

- [ ] 在一次性数据库上验证全新安装和升级迁移。
- [ ] Windows/Linux Agent 使用独立凭据认证，并能在 Master 重启后重连。
- [ ] 使用真实 Agent 验证设备清单、指标、软件包下载、安装结果和错误路径。
- [ ] 在隔离客户端上验证策略和重复计划任务。
- [ ] 在支持的终端中验证 TUI 导航和破坏性操作确认。

## 安全与运维

- [ ] 管理员和 Agent 密钥未提交到 Git 或写入日志。
- [ ] 为非隔离网络记录 TLS/WSS 与防火墙要求。
- [ ] 测试备份与恢复。
- [ ] 破坏性维护命令要求明确确认。
- [ ] 文档说明已知限制和升级步骤。

## 发布元数据

- [ ] 版本号与 changelog 保持一致。
- [ ] 五种语言的文档均包含当前安装、安全和限制说明。
- [ ] 所有检查通过后才创建 `vX.Y.Z` 标签。
- [ ] 发布校验和与发行说明。
