# 终端界面（lndp）

`lndp` 是通过 Master API 管理客户端和已上传软件包的交互式终端工具。安装和删除操作会影响真实设备与文件。

## 标签页

- **Clients** — 浏览/搜索客户端、选择目标并刷新连接状态。
- **Devices** — 查看所选在线 Agent 的设备清单和诊断提示。
- **Monitor** — 查看最新 CPU/RAM/uptime 快照。指标按需请求，尚未保存为历史时间序列。
- **Files / Install** — 双栏浏览本地文件和 Master 软件包，标记、上传、下发安装，并在确认后删除已上传的软件包。

## 快捷键

| 按键 | 操作 |
|---|---|
| `1`–`4` / `Tab` | 切换标签页 |
| `↑` / `↓` 或 `j` / `k` | 移动列表选择 |
| `Space` | 标记客户端或软件包 |
| `/` | 搜索客户端 |
| `U` | 上传已标记的本地文件 |
| `I` | 向所选客户端下发所选软件包 |
| `M` | 在支持时切换安装模式 |
| `X` 后按 `Y` | 确认删除 Master 上的软件包 |
| `R` | 刷新当前视图 |
| `?` / `F1` | 打开快捷键帮助 |
| `Q` | 退出 |

## 注意事项

- 按 `I` 前请确认目标客户端和软件包；这会发送真实安装命令。
- MSI 支持静默/基本 UI/完整 UI 模式；EXE 和 Linux 安装程序的行为取决于厂商参数。
- 设备查询超时可能表示 Agent 离线、版本过旧或 Windows PnP/WMI 查询较慢。超时不等于设备列表为空。
- 终端宽度和 Unicode 显示取决于终端模拟器。建议使用支持 UTF-8 的现代终端，列被截断时扩大窗口。
