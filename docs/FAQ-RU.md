## Общие вопросы

### Что такое LANdapter?

LANdapter – это клиент-серверная система для централизованной установки драйверов и программного обеспечения на множество машин в локальной сети. Мастер управляет агентами через WebSocket, раздаёт файлы и отслеживает установки.

### Для каких операционных систем подходит?

- **Мастер**: Windows, Linux (рекомендуется Linux).
- **Агенты**: для Windows и Linux реализованы обработчики установки. Выполнение установок на macOS пока не поддерживается.

### Есть ли веб-интерфейс?

Да, React-панель управления. Она позволяет просматривать клиентов, загружать файлы, отправлять задания и видеть результаты.

### Нужна ли аутентификация?

Административные REST-эндпоинты требуют `Authorization: Bearer <LANDAPTER_ADMIN_TOKEN>` (случайный секрет длиной не менее 32 символов). Для агентов используются персональные токены, выдаваемые в настройках. Аутентификация не шифрует трафик: вне доверенной локальной сети используйте TLS/WSS и сетевые ограничения.

## Установка и настройка

### Как изменить порты мастера?

Измените `http_port` и `ws_port` в `master.yaml`. Агенты должны указывать новый `master_port` (WebSocket). Не забудьте открыть порты в брандмауэре.

### Как указать пароль БД, не сохраняя его в YAML?

Используйте переменную окружения `DB_PASSWORD`. В YAML можно оставить поле `password` пустым. Viper автоматически подхватит значение из окружения.

### Почему агент не подключается?

- Проверьте, что мастер запущен и порт 8081 открыт.
- Проверьте `master_host` в `agent.yaml` – должен указывать IP мастера.
- Убедитесь, что между агентом и мастером нет брандмауэра.
- Посмотрите логи агента – там будет конкретная ошибка.

### Какие права нужны агенту?

- Для установки драйверов (`.inf`) на Windows требуются права администратора (запуск от имени администратора).
- Для Linux требуется `sudo` для установки пакетов (`.deb`, `.run`). Настройте sudo без пароля для агента или используйте SUID.

### Можно ли запустить мастера без PostgreSQL?

Нет, PostgreSQL обязателен. Можно использовать SQLite, но это потребует доработки (реализовать интерфейс `storage.Storage`).

## Использование

### Как загрузить файл?

Через веб-интерфейс: перейдите на страницу «Файлы» и перетащите файл или кликните для выбора. Или через API: `POST /api/v1/upload` с multipart/form-data.

### Какие форматы файлов поддерживаются?

- Windows: `.exe`, `.msi`, `.inf`.
- Linux: `.deb`, `.run`, `.tar`, `.tar.gz`, `.tar.bz2`, `.tgz`.
- Другие форматы можно добавить, расширив `installer.go`.

### Что означает режим установки «тихая» и «интерактивная»?

- **Тихая** – установка без UI, все ответы на вопросы принимаются по умолчанию (например, `/S` для EXE, `/qn` для MSI).
- **Интерактивная** – появляется стандартный интерфейс установщика, пользователь может выбирать параметры.

### Как получить статистику с клиента?

В веб-интерфейсе на странице клиентов нажмите «Подробности» и затем «Статистика». Или используйте API: `GET /api/v1/clients/{id}/stats`.

### Что такое снапшоты?

Это снимок состояния системы (CPU, память, uptime) до и после установки. Они сохраняются в базе данных и помогают оценить влияние установки на производительность.

### Как работает Wake-on-LAN?

Мастер отправляет магический пакет на MAC-адрес клиента. Для этого клиент должен быть в сети и поддерживать WOL. Агент при подключении передаёт свой MAC-адрес.

## Устранение неполадок

### Ошибка «failed to connect to DB»

- Убедитесь, что PostgreSQL запущен.
- Проверьте параметры подключения в `master.yaml` (хост, порт, пользователь, пароль).
- Проверьте, что база данных существует и миграции применены.
- Если используется SSL, проверьте `sslmode`.

### Агент переподключается каждую минуту

- Это нормально, если мастер не отвечает на пинг. Проверьте, что мастер не перегружен и порт 8081 открыт.
- В логах агента может быть ошибка чтения – проверьте стабильность сети.

### Файлы не скачиваются агентом

- Агент скачивает файл через `GET /api/v1/agent/files/{id}` с bearer-токеном и заголовком `X-Agent-ID`.
- Проверьте, что файл существует в папке `uploads/`.
- Агент должен иметь доступ к HTTP(S)-порту из `master_http_port` (по умолчанию 8080), помимо WebSocket-порта.

### Установка .inf не работает

- Проверьте, что агент запущен с правами администратора.
- В Windows может потребоваться перезагрузка после установки драйвера.

### Веб-интерфейс не загружается

- Убедитесь, что фронтенд собран (`npm run build`) и статика раздаётся веб-сервером (например, Nginx).
- Проверьте, что API-прокси правильно настроен (например, `/api` → `http://localhost:8080`).
- Откройте консоль браузера (F12) – там могут быть ошибки CORS или 404.

## Вопросы по разработке

### Как добавить поддержку нового типа файлов?

1. В `internal/agent/installer.go` добавьте новый case в `installOne` для нужного расширения.
2. Реализуйте метод установки (например, `installAppImage`).
3. Добавьте необходимые аргументы в `installer_args` (если нужно).
4. Обновите документацию.

### Как добавить новый API-эндпоинт?

1. В `internal/master/handlers.go` создайте функцию-обработчик.
2. Зарегистрируйте её в `server.go` (в `Start()`).
3. Обновите `README.API.md`.

### Как запустить интеграционные тесты?

Установите тестовую базу данных, задайте переменные окружения и выполните `make test-integration`. Тесты создают и удаляют временные таблицы.

## Дополнительно

### Где хранятся логи?

Мастер и агент пишут логи в stdout. При запуске через systemd логи можно смотреть через `journalctl`. Для перенаправления в файл используйте перенаправление вывода в скрипте запуска.

### Как обновить версию?

- Остановите сервис.
- Скачайте новую версию, пересоберите бинарники.
- Примените новые миграции (`make migrate-up` или вручную).
- Запустите сервис.

### Можно ли использовать LANdapter в облаке?

Только при грамотной защите: используйте TLS/WSS, надёжные секреты, firewall или VPN и не публикуйте PostgreSQL. Для admin API и персональных токенов агентов реализована аутентификация, но проект продолжает развиваться.

### Есть ли планы на будущее?

В планах: Master CLI, групповые политики, планировщик заданий, поддержка дополнительных форматов и улучшенный парсинг драйверов.
