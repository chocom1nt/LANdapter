# リリース準備チェックリスト

## ビルドと依存関係

- [ ] `go.mod` が要求する Go バージョンで CI が成功する。
- [ ] フロントエンドテスト、本番ビルド、依存関係監査が成功する。
- [ ] 依存関係の advisory を確認し、修正またはリスク判断を記録する。
- [ ] クリーンな checkout から Docker イメージをビルドできる。

## 機能

- [ ] 使い捨て DB で新規インストールと更新マイグレーションを確認する。
- [ ] Windows/Linux Agent が個別認証情報で接続し、Master 再起動後に再接続する。
- [ ] 実 Agent でデバイス一覧、統計、パッケージ取得、インストール結果、エラー経路を確認する。
- [ ] 隔離端末でポリシーと繰り返しスケジュールを確認する。
- [ ] 対応端末で TUI の操作と破壊的操作の確認を検証する。

## セキュリティと運用

- [ ] 管理者/Agent の秘密情報が Git やログに含まれていない。
- [ ] 非隔離ネットワーク向けの TLS/WSS とファイアウォール要件を記載する。
- [ ] バックアップと復元をテストする。
- [ ] 破壊的な保守コマンドに明示的な確認がある。
- [ ] 既知の制約と更新手順が文書化されている。

## リリース情報

- [ ] バージョン番号と changelog を同期する。
- [ ] 5 言語すべてのガイドが現在の手順・セキュリティ・制限を反映している。
- [ ] チェック成功後にのみ `vX.Y.Z` タグを作成する。
- [ ] チェックサムとリリースノートを公開する。
