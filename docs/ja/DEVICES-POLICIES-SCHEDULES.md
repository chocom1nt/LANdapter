# デバイス一覧、ポリシー、スケジューラー

現在実装されている範囲と制約を説明します。デバイス一覧は診断情報であり、ドライバーを自動インストールする推奨ではありません。

## デバイス一覧

- Windows では利用可能な Plug and Play / WMI 情報から Hardware ID、メーカー、ドライバー提供元/バージョン、問題コードを収集します。Linux ではシステムインターフェースから PCI/USB デバイスとドライバーのバインドを調べます。
- OS の権限、デバイス種別、WMI の状態、利用可能なツールにより一部の項目が欠ける場合があります。不完全な結果と、正常に取得した空の一覧は異なります。
- LANdapter は診断の手掛かりを示しますが、ベンダーカタログ検索、ドライバーのダウンロード、署名検証、自動インストールは行いません。

## グループポリシー

- ポリシーはアップロード済みパッケージと OS 部分文字列フィルターを関連付け、手動で配信できます。
- 永続的な動的グループ、AD/LDAP ターゲティング、タグ、高度な対象ルールは未実装です。
- まずテスト端末でポリシーを確認してください。配布元、署名、引数、再起動動作、冪等性を検証します。

## スケジューラー

- スケジュールは設定した間隔でポリシー/パッケージのインストールを繰り返します。汎用タスクエンジンや cron のようなカレンダー指定ではありません。
- 繰り返し実行によりソフトウェアが再インストール/修復されたり、再起動が発生したりする場合があります。信頼できる冪等なインストーラーを使い、結果を監視してください。

## 運用上の安全

- 大規模展開の前にテスト端末を使ってください。信頼できないネットワークでは Master の HTTP/WebSocket を非公開にするか TLS/WSS で保護してください。
- PostgreSQL と uploads のバックアップを維持してください。DB のクリア/リセットは破壊的操作であり、通常の保守作業として実行しないでください。
