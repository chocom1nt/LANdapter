# ターミナル UI（lndp）

`lndp` は Master API を通じてクライアントとアップロード済みパッケージを管理する対話型ターミナルクライアントです。インストールや削除は実際の端末・ファイルに作用します。

## タブ

- **Clients** — クライアントの一覧・検索、対象選択、接続状態の更新。
- **Devices** — 選択したオンライン Agent のデバイス一覧と診断情報。
- **Monitor** — 最新の CPU/RAM/uptime。メトリクスは要求時に取得され、履歴時系列としては保存されません。
- **Files / Install** — ローカル/Master の二画面パッケージ管理。ファイルのマーク、アップロード、インストール配信、確認付き削除を行います。

## キーボード操作

| キー | 操作 |
|---|---|
| `1`–`4` / `Tab` | タブ切り替え |
| `↑` / `↓` または `j` / `k` | リスト移動 |
| `Space` | クライアントまたはパッケージをマーク |
| `/` | クライアント検索 |
| `U` | マークしたローカルファイルをアップロード |
| `I` | 選択パッケージを選択クライアントへ配信 |
| `M` | 対応する場合にインストールモードを変更 |
| `X` の後に `Y` | アップロード済みパッケージの削除を確認 |
| `R` | 現在の画面を更新 |
| `?` / `F1` | キーボードヘルプ |
| `Q` | 終了 |

## 注意事項

- `I` を押す前に対象端末とパッケージを確認してください。実際のインストール命令が送信されます。
- MSI はサイレント/基本 UI/フル UI をサポートします。EXE と Linux インストーラーの動作はベンダーと引数に依存します。
- デバイス取得のタイムアウトは、Agent がオフライン、旧バージョン、または Windows PnP/WMI の照会に時間がかかる場合に発生します。タイムアウトは「デバイスなし」と同じ意味ではありません。
- 端末エミュレーターによって幅と Unicode 表示は異なります。UTF-8 対応の端末を使用し、列が切れる場合は幅を広げてください。
