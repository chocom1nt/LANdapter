# Тестирование

## Автоматические тесты

```sh
make test
```

Команда запускает тесты Go и проверки переводов frontend (`npm test` в `web/`). Проверки словарей используют встроенный тестовый runner Node.js и не требуют установки браузерных зависимостей.

## Тестовые клиенты для веб-интерфейса и TUI

Когда PostgreSQL из Compose запущен и миграции применены:

```sh
make seed-demo-agents
```

Команда добавляет шесть детерминированных **записей для тестирования интерфейса**, а не настоящих подключённых агентов. Они подходят для проверки таблицы клиентов, поиска, счётчиков и списка TUI. Все фиктивные записи намеренно офлайн, поскольку за ними нет запущенных WebSocket-агентов. API клиентов определяет статус по активным подключениям, а не по устаревшему флагу в БД.

Удалить только эти записи:

```sh
make clear-demo-agents
```

Не запускайте эти команды против production-базы.

## Проверка сборки

```sh
cd web && npm ci && npm run build
```

Для `go test ./...` используйте версию Go, указанную в `go.mod`. Для интеграционных тестов отдельно настройте тестовую БД и зависимости.
