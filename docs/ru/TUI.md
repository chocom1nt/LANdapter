# Терминальный интерфейс Master (`lndp`)

`lndp` — экспериментальный терминальный клиент для авторизованного API Master. Он умеет просматривать записи клиентов, фильтровать список, запрашивать инвентарь устройств и текущие показатели онлайн-агента. Интерфейс пока только для чтения: установка ПО и редактирование политик остаются в веб-панели.

## Быстрый запуск

Из корня репозитория:

```sh
make setup
make up
make build-tui
make run-tui
```

TUI автоматически загружает `LANDAPTER_ADMIN_TOKEN` из `.env`. Переопределяйте `LANDAPTER_API_URL`, только если Master API находится не по адресу `http://127.0.0.1:8080/api/v1`.

В Windows:

```powershell
.\bin\lndp.exe
```

## Управление

- `↑` / `↓` или `j` / `k` — выбрать клиента
- `/` — фильтр по имени хоста, ОС, MAC или ID
- `1` или `c` — список клиентов
- `2` или `d` — запросить инвентарь устройств и диагностику драйверов выбранного клиента
- `3` или `s` — запросить текущую статистику выбранного агента
- `Tab` — переключение между клиентами, устройствами и статистикой
- `Enter` — показать/скрыть подробности выбранного клиента в списке
- `r` — обновить список клиентов
- `Esc` — сбросить фильтр
- `q` или `Ctrl+C` — выход

Вкладки устройств и статистики требуют, чтобы выбранный агент был онлайн и использовал совместимую версию. Инвентарь Windows основывается на данных Plug and Play о проблемах устройств; в Linux проверяются устройства PCI/USB и привязка драйвера в sysfs. Отметка о проблеме — это подсказка для диагностики, а не рекомендация устанавливать произвольный драйвер. Перед развёртыванием проверьте ID оборудования и пакет производителя.

TUI и формат инвентаря экспериментальные и могут меняться.
